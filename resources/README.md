# Resources

Files listed on the site's "Additional material" page — reference
material that isn't tied to a specific week (lecture notes, summary
sheets, etc.).

Drop a file here, then add an entry to the `RESOURCES` array in
`../index.html`:

```js
{ title: "Summary Sheet", href: "resources/summary_sheet.pdf", dlname: "CS301-summary-sheet.pdf" }
```

- `title` — label shown on the page.
- `href` — path to the file here in `resources/`.
- `dlname` — filename the browser saves it as on download.

Commit & push; the new row appears automatically.
