On the slide, the controller is a block kP + kD·s. On the real cart it is a few lines of code on a microcontroller that rides along on the cart. An encoder at the hinge measures the tilt θ, the code computes u, and the wheel motor accelerates the cart. Accelerating the hinge sideways tips the pendulum, exactly like a torque would: with the cart acceleration a, the pendulum obeys θ̈ = (g/ℓ)θ − a/ℓ, so a = −ℓ·u gives back the slide's model. Drag the pendulum, tap it, or switch the controller off.
