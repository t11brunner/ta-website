Bordered card for a downloadable or actionable item — round mono badge, uppercase label, headline name, status line, arrow glyph that nudges on hover. Dims to a `—` placeholder when unavailable.

```jsx
<ActionCard badge="EX" label="Exercise slides" name="CS301-week-05-exercise.pdf" status="available · click to download" available href="slides/week-05.pdf" />
```

Lifted from the source site's `.dl-card` (downloads grid).
