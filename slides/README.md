# Slides

Drop each week's lecture slides here as a PDF named by week number:

```
slides/week-01.pdf
slides/week-02.pdf
slides/week-05.pdf
...
```

Then set `pdf:true` for that week in the `WEEKS` array in `../index.html`.
The week's download button on the site will activate automatically and serve
the file as `CS301-week-NN.pdf`.
